Tus apuntes, organizados.
La búsqueda incluye texto de imágenes.

 LISTO PARA EL EXAMEN

Encontrá el dato. Abrí la fuente.

  1. Buscá palabras como «clobetasol», «p16» o «HSIL márgenes». No hacen falta tildes. También reconoce HPV/VPH, HIV/VIH y biopsia/BX.
  2. Filtrá por módulo, tema o tipo de contenido. El resumen aparece primero; también se busca en las notas y el texto de las diapositivas.
  3. Abrí la fuente para ver la imagen y ampliar tablas o algoritmos. En el visor, usá los cursores del teclado para pasar de una fuente a otra.
  4. Guardá fichas con la estrella. Se recuerdan en este navegador cuando permite almacenamiento local.

El resumen sintetiza el material del curso. El texto extraído de imágenes es automático: cotejá cifras, dosis y esquemas con la captura. Las preguntas conservan respuesta solo cuando la fuente muestra una clave explícita.

Atajos: / o Ctrl K para buscar · Esc para cerrar el visor o limpiar la búsqueda.

Para compartir: copiá la carpeta TGI completa. Si recibís un ZIP, extraelo y abrí index.html. No necesitás OneNote, instalación ni conexión.
